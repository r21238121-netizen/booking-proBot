# FloraBot - Telegram-бот для заказа цветов

FloraBot - это Telegram-бот, который позволяет пользователям просматривать каталог цветов, оформлять заказы и отслеживать их статус. Администраторы могут управлять заказами и каталогом через Telegram-интерфейс.

## Функциональность

### Для пользователей:
- Просмотр каталога букетов с фото, описанием и ценой
- Добавление товаров в корзину
- Оформление заказа с указанием адреса доставки, даты и времени
- Возможность добавить комментарий к заказу
- Поддержка оплаты при получении

### Для администраторов:
- Просмотр новых заказов
- Изменение статуса заказов
- Уведомление пользователей об изменениях статуса
- Управление каталогом цветов

## Установка и запуск

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` и укажите токен бота и ID администраторов:
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_IDS=123456789,987654321
DATABASE_URL=sqlite:///./florabot.db
```

3. Запустите бота:
```bash
python -m bot.main
```

## Структура проекта

- `bot/` - основной код бота
- `bot/handlers/` - обработчики команд и сообщений
- `bot/keyboards/` - клавиатуры бота
- `bot/models/` - модели базы данных
- `static/images/` - изображения для каталога
